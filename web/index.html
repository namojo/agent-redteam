웹 콘솔

CLI와 같은 엔진(src/core)을 브라우저에서 그대로 실행합니다. 판정·게이트·리포트는 모두 엔진이 만들고, 이 화면은 결과를 보여 주기만 합니다.

브라우저 안의 mock 에이전트를 상대로 점검합니다. 네트워크 요청은 보내지 않습니다. 취약한 에이전트에 공격을 실행한 뒤, 방어 가드 프롬프트를 켜고 다시 시험해 차단률을 비교할 수 있습니다.

mock 에이전트
공격 변형

기본(변형 없음)은 항상 포함됩니다. 고른 변형마다 단일 턴 프로브가 한 벌씩 추가됩니다.

구성

“방어 적용 후 재시험”은 직전 “공격 실행”과 같은 설정에 방어(attack.defend)만 켜서 다시 실행하고 전후 차단률을 비교합니다. 공격을 한 번 실행하면 활성화됩니다.

브라우저에서 대상 API를 직접 호출합니다.

  • 대상이 CORS를 허용해야 합니다(Access-Control-Allow-Origin). 허용하지 않으면 모든 케이스가 오류로 끝나고 게이트는 FAIL입니다.
  • 사내·내부망 엔드포인트, 사설 CA·TLS 설정이 필요한 대상은 CLI(npx agent-redteam run)를 쓰십시오. 웹에서는 TLS·CA를 설정할 수 없습니다.
  • Anthropic API를 브라우저에서 부르려면 헤더 anthropic-dangerous-direct-browser-access: true가 필요합니다.
  • API 키는 이 탭의 메모리에만 있습니다. 저장하지 않으며 새로고침하면 사라집니다. 리포트에는 키·헤더 값이 기록되지 않습니다.
대상

값의 {{KEY}}는 API 키로 바뀝니다. 키를 쓰지 않는 사용자 정의 인증 헤더도 여기 넣습니다.

HTTP 템플릿

{{PROMPT}} 마지막 사용자 입력, {{MESSAGES}} 대화 메시지 목록, {{SYSTEM}} 시스템 지시, {{KEY}} API 키. {{MESSAGES}}가 없으면 멀티턴을, {{SYSTEM}}이 없으면 방어 가드를 보낼 수 없습니다.

시스템 프롬프트와 카나리

시스템 프롬프트에 심어 둔 고유 문자열. 응답에 나오면 시스템 프롬프트 유출(LLM07)로 판정합니다. 없으면 LLM07은 judge 없이 미결입니다.
